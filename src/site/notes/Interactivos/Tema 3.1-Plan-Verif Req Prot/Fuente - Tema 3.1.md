# Fuente - Tema 3.1

Tema 3.1: Planificación del Prototipo – Verificación de Requisitos del Prototipo (51 páginas). Cubre: introducción (Bill Buxton, proceso iterativo), requisitos de software (4 categorías: negocio/marketing, funcionales, técnicos, de usabilidad), transformación de suposiciones en requisitos (3 pasos: recogida, inventario, priorización), requisitos de prototipado vs requisitos de software, y el ciclo de prototipado (idea → suposiciones → wireframe rápido → prototipo interactivo → iteración).

## Registro de lectura
- p. 1: portada
- p. 2: índice
- p. 3-5: introducción (Buxton, proceso iterativo, contexto necesario, contenido y fidelidad)
- p. 6-9: prototipado de requisitos (4 categorías, balance de supuestos y requisitos)
- p. 10-14: requisitos funcionales, técnicos, usabilidad
- p. 15-20: requisitos no son requisitos de software, recopilación de requisitos
- p. 21-30: paso 1 (recogida de requisitos), paso 2 (inventario), paso 3 (priorización)
- p. 31-40: requisitos de prototipado, iteraciones, figura 3.1
- p. 41-51: pasos adicionales (hoja de trabajo 3.1, validación de requisitos, conclusiones)

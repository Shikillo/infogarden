# Métodos de prototipado

> [!abstract] En una frase
> Son los procedimientos que se utilizan para crear un prototipo: prototipado en papel, storyboards, wireframes, prototipado con software, etc.

## ¿Qué problema resuelve?
Permiten elegir la forma más adecuada de representar una idea, ajustándose a la audiencia, el estado del proyecto, la velocidad y las herramientas disponibles.

## Qué es
Los métodos son los distintos procedimientos que se usan para crear un prototipo. Ejemplos incluyen:
- **Prototipado en papel**: dibujar borradores a mano o con lápiz, ágil y para uso de baja fidelidad.
- **Storyboards**: visualizar secuencias de interacción a través de una serie de bocetos.
- **Wireframes**: maquetas de baja fidelidad de pantallas, enfocadas en la estructura y navegación.
- **Prototipado con software**: crear prototipos en aplicaciones como Office (Word, PowerPoint), Visio, Acrobat, herramientas de desarrollo o aplicaciones de prototipado.

El material destaca que cualquiera puede usar los métodos con las herramientas que ya conoce (Office, papel, etc.). El método elegido debe ajustarse a las necesidades del prototipo, no a una herramienta en particular.

## Cómo podrías haberlo descubierto
El material muestra que un prototipo efectivo puede ser creado con las herramientas más sencillas si el método se elige de acuerdo con el objetivo (por ejemplo, para un rápido borrador, usar papel; para fidelidad moderada, usar PowerPoint).

## Ejemplo
> [!example]
> Para validar un flujo de tareas con una carta de navegación, un equipo usa un prototipo de papel con un boceto de pantallas que se conectan por flechas. (Material, Tema 1 p. 13)

## Errores comunes
> [!warning]
> Pensar que un método necesita una herramienta costosa. El material dice: "Casi cualquier herramienta de software puede ser un método de prototipado: Office, Visio, Acrobat".
> Usar un método inapropiado (por ejemplo, prototipado con código para una validación rápida), lo que hace que el prototipo no cumpla con su propósito.

## Autoevaluación
> [!question]- ¿Qué método es mejor para una prueba rápida con usuarios sobre la navegación de una aplicación móvil?
> Un prototipo de papel con storyboards es la opción más rápida para probar el flujo de navegación.

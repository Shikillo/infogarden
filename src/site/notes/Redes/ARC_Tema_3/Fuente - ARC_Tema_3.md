# Fuente - ARC_Tema_3

Tema 3: Protocolos y Dispositivos en Redes de Área Local (dominios, repetidor/hub, puente/switch, router, IP, ARP, subredes).

## Estructura
- p. 1-2: Índice y repaso
- p. 3-4: Diferencias redes, conceptos previos (rack, patch panel)
- p. 5-6: Dominio de colisión, dominio de difusión, tramas unicast/difusión
- p. 7-10: Repetidor (nivel 1), Hub (multipuerto, dominio colisión/difusión)
- p. 11-12: Puente (MAC/Puerto, nivel 2, aprendizaje transparente)
- p. 13-15: Switch (MAC/Puerto, tipos Store-and-Forward, Cut-Through, Fragment Free, Adaptative)
- p. 16-17: Switch divide colisión, expande difusión
- p. 18-20: Router (nivel 3, IP, interfaces heterogéneas, tablas encaminamiento)
- p. 21-24: Direccionamiento IP (32 bits, clases A/B/C, máscara de red, notación /, redes privadas RFC1918)
- p. 25-29: ARP (resolución IP→MAC, difusión, caché, refinamientos, formato)
- p. 30-37: Formato paquete IP (versión, cabecera, servicio, checksum, opciones), fragmentación (MTU, flags DF/MF, offset, reensamblaje en destino)
- p. 38-40: Encaminamiento IP (directo/indirecto, diálogo directo/indirecto), TTL, protocolo, fragmentación ejemplo
- p. 41-49: Subnetting / Supernetting (máscaras variables), Gateway, resumen

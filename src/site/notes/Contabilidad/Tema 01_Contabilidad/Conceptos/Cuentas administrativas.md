# Cuentas administrativas

> [!abstract] Sistema de registro de compraventa con criterio valorativo homogéneo (sin componente de resultado en la cuenta de mercaderías). Uso de cuenta única o desdoblamiento.

## Qué es
Dos procedimientos administrativos (p. 41-47):
- **Procedimiento de cuenta única**: Mercaderías como cuenta activa; compras y ventas registradas a precio de adquisición/venta; la diferencia es resultado (beneficio/pérdida) directa.
- **Procedimiento de desdoblamiento**: separa Mercaderías (activo), Compras (precio adq.), Ventas (precio venta), Coste de ventas (gasto) y Ventas de mercaderías (ingreso). Ejemplo p. 47: compra 35.000; venta 50.000 (c/36.000 coste) y 26.000 (c/33.000 coste); coste total 69.000; venta total 76.000; resultado 7.000.

## Ejemplo (desdoblamiento p. 47)
> [!example]
> 1. Compra a crédito 35.000 → Mercaderías 35.000 / Proveedores 35.000
> 2. Venta 50.000 → Bancos 50.000 / Venta merc. 50.000; Coste venta 36.000 / Mercaderías 36.000
> 3. Venta 26.000 → Bancos 26.000 / Venta merc. 26.000; Coste venta 33.000 / Mercaderías 33.000
> Resultado: 76.000 − 69.000 = 7.000.

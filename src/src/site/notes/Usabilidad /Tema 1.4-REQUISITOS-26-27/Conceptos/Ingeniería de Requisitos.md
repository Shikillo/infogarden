# Ingeniería de Requisitos
> [!abstract] En una frase
> Proceso de desarrollo y gestión de requisitos enfocado en obtener, analizar, especificar, validar y administrar cambios con trazabilidad.

## Qué es
La IR proporciona mecanismos para entender lo que el cliente quiere, analizar necesidades, evaluar factibilidad, negociar soluciones razonables, especificar sin ambigüedades, validar y administrar requisitos conforme se transforman en sistema operacional. Según LizkaYohanyHerrera, sus principales beneficios son gestionar necesidades estructuradamente, mejorar la capacidad de predecir cronogramas y resultados, disminuir costos y retrasos (especialmente porque reparar errores no descubiertos a tiempo es muy caro), mejorar la calidad del software (funcionalidad, facilidad de uso, confiabilidad, desempeño) y mejorar la comunicación entre equipos para evitar el rechazo de usuarios finales.

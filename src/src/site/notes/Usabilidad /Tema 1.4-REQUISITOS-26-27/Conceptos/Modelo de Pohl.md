# Modelo de Pohl
> [!abstract] En una frase
> Modelo iterativo de cuatro actividades básicas: elicitación, negociación, especificación/documentación y validación/verificación.

## Qué es
Según Pohl (1997, LNCS), el modelo de proceso de la ingeniería de requisitos es iterativo y propone cuatro actividades básicas: elicitación (hacer explícito el conocimiento oculto), negociación (alcanzar acuerdos evitando conflictos emocionales y haciendo explícitas alternativas y razones), especificación/documentación (usar varias notaciones para que todos entiendan, evitando lenguaje natural propenso a malinterpretaciones) y validación/verificación (comprobar que corresponden con necesidades reales y cumplen criterios de calidad). El documento de análisis de requisitos resultante debe comunicar servicios, restricciones, propiedades, sistemas cooperantes, dominio de aplicación y hardware.
